# Calculadora de Ganho de Capital

Ferramenta interna do Gaia Silva Gaede Advogados - PR para apurar o ganho de capital na alienação de imóveis por pessoas físicas, com base na Instrução Normativa SRF nº 84/2001.

Todo o cálculo roda no navegador; nenhum dado é enviado para fora da máquina do usuário. Os resultados têm caráter consultivo e não substituem a análise individual de cada caso.

## Como rodar

```
npm install
npm run dev
```

- `npm test`: executa os testes (Vitest).
- `npm run lint`: verifica os tipos (`tsc --noEmit`).
- `npm run build`: gera a versão de produção em `dist/`.
